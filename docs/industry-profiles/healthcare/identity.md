# Healthcare Identity Profile

## Objective

Apply the Enterprise Zero Trust Identity Architecture to healthcare information systems and clinical environments.

## Identity Priorities

- Workforce identity
- Clinical role-based access
- Least privilege
- Temporary administrative access
- Audit logging
- Identity lifecycle management

## Implementation Considerations

Healthcare organizations require secure access to clinical systems while protecting electronic health information and supporting diverse care teams.

## Architecture Components

- IAM Roles
- IAM Identity Center
- AWS STS
- CloudTrail
- AWS Config

## Alignment

Example architectural references include:

- HIPAA Security Rule
- NIST SP 800-207
- NIST Cybersecurity Framework
