# Industry Profiles

## Purpose

The Zero Trust Reference Architecture is designed to provide a common security architecture that can be implemented across multiple critical infrastructure sectors.

The underlying architecture remains consistent across industries. What changes are the implementation priorities, regulatory considerations, operational constraints, and deployment guidance.

This section demonstrates how the same architecture can be adapted for different operational environments without changing the core security principles.

---

# Industry Profiles

| Industry | Primary Focus |
|-----------|---------------|
| Federal | Government systems, Zero Trust maturity, FedRAMP-aligned deployments |
| Financial Services | Payment systems, transaction integrity, identity governance |
| Healthcare | Clinical systems, electronic health information, workforce identity |
| Energy | Critical infrastructure resilience, OT/IT identity protection |

---

# Common Architecture

All industry profiles implement the same enterprise architecture documented under:

- docs/architecture/
- reference/aws/

Only implementation guidance differs between industries.

---

# Implementation Areas

Each industry profile documents:

- Identity
- Network
- Data Protection
- Application Security
- Detection & Monitoring
- Security Automation
- Governance & Compliance

As additional implementation stories are completed, each profile will expand accordingly.
