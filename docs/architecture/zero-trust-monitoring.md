# Zero Trust Monitoring

Zero Trust requires continuous verification of every identity, workload, and transaction.

## Principles

- Never trust.
- Always verify.
- Monitor continuously.
- Log every administrative action.
- Detect abnormal behavior.
- Protect audit logs.
- Automate alerting.
- Preserve forensic evidence.

Monitoring should cover:

- Identity
- Network
- Compute
- Storage
- Data
- Applications
- APIs
