# Compliance & Control Mappings

## Purpose

This section documents how the Zero Trust Reference Architecture aligns with widely adopted cybersecurity frameworks and industry standards.

The objective is to demonstrate architectural alignment rather than claim certification or regulatory compliance.

The mappings serve as implementation guidance to help organizations understand how repository capabilities support common security control objectives.

---

## Frameworks

- NIST SP 800-53
- NIST SP 800-207
- NIST Cybersecurity Framework
- FedRAMP
- PCI DSS
- HIPAA Security Rule
- NERC CIP
- ISO/IEC 27001

---

## Repository Approach

The repository is organized around security capabilities.

Framework mappings demonstrate how those capabilities relate to common control families without duplicating architecture or implementation.
