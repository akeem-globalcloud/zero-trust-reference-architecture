# Enterprise Control Catalog

## Purpose

The Enterprise Control Catalog provides a centralized view of the security capabilities implemented throughout the Zero Trust Reference Architecture.

Each implementation story contributes one or more reusable security capabilities.

Those capabilities are then mapped to multiple cybersecurity frameworks.

---

| Capability | Story | Repository Area |
|------------|-------|-----------------|
| Identity Foundation | ZT-002 | terraform/modules/identity |
| Zero Trust Architecture | ZT-002 | docs/architecture |
| Secure Network Architecture | ZT-003 | terraform/modules/network |
| Data Protection | ZT-004 | terraform/modules/kms |
| Application Security | ZT-005 | policies |
| Detection Engineering | ZT-006 | detections |
| Security Automation | ZT-007 | automation |
| Governance | ZT-008 | docs/compliance |
